# Equal Probability Is an Assumption: replication archive

[![DOI](https://zenodo.org/badge/1385873084.svg)](https://doi.org/10.5281/zenodo.22943919)

This repository contains the code, frozen specification, and archived results for the decision-boundary experiment in *Equal Probability Is an Assumption: Choosing Probability Samples for Public Audits*. All data are synthetic and generated by the code. No confidential or government data are used. Releases of this repository are archived on Zenodo; the DOI [10.5281/zenodo.22943919](https://doi.org/10.5281/zenodo.22943919) always resolves to the latest version.

| `results/` | Archived outputs of the frozen pipeline |

| `environment.lock.txt` | Package versions |

## Post-freeze diagnostics (`r2_diagnostics/`)

| Script | Purpose |
|---|---|
| `audit_fallback.py` | Regenerates all 14,400 planning fits. For each fit it records linear-programming separation, fitting-routine warnings, convergence, maximum coefficient, and the archived fallback decision. |
| `audit_summary.py` | Summarizes the audit by planning condition |
| `separation_sensitivity.py` | Applies the separation-aware procedure (intercept-only fallback for every separated fit) to the conditions containing separated fits that the archived rule retained. The archived-rule rows reproduce `results/summary/estimated_summary.csv`. |
| `coverage_by_fit.py` | Reruns the complete-procedure Monte Carlo with the archived seeds. The output matches `results/monte_carlo/complete_procedure_final.csv` byte for byte. It then summarizes coverage at the planning-fit level. |
| `hajek_realized.py` | Compares the simulated conditional-Poisson variance with the Hájek approximation evaluated on the same realized outcome vector. It requires `coverage_by_fit.py` to have been run first. |
| `tail_uncertainty.py` | Planning-level standard errors, bootstrap intervals, and top-fit shares for the sparse-planning means, under both fallback rules. It requires `separation_sensitivity.py` to have been run first. |

## Environment

- **Python 3.14.7:** numpy 2.5.3, scipy 1.18.1, pandas 3.0.6, statsmodels 0.15.0, sympy 1.14.0, pyarrow 25.0.1, pytest 9.1.1.
- **R 4.5.1 with `sampling` 2.11:** used only by `tests/test_cps_vs_R.py`.
- **Exact pins:** `environment.lock.txt`.

## Reproduce

```sh
python3 -m venv .venv
.venv/bin/pip install numpy scipy pandas statsmodels sympy pyarrow pytest
# optional, for tests/test_cps_vs_R.py:
#   mkdir .Rlib && R_LIBS_USER=.Rlib Rscript -e 'install.packages("sampling", repos="https://cloud.r-project.org")'
./run_all.sh
```

The full run takes about 30 minutes on a laptop. The pipeline is deterministic (fixed seeds), and regenerated CSV outputs can be compared with the archived files using `shasum -a 256 -c SHA256SUMS.txt`.
